# Gold (XAU/USD) live & forecast

A single-page app: 1–2 day buy/sell forecast from 5-minute history, a Trade Tracker with take-profit / cut-loss alerts, and a TradingView live chart.

Each visitor needs their own free [Twelve Data](https://twelvedata.com) API key. Keys and settings are stored only in the visitor's own browser; nothing is stored in this repository.
